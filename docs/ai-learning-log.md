## Summary of Concepts Learned During the CampusFlow Project

Throughout the CampusFlow project, I learned how to develop a Python application using professional software engineering practices.

1\. Modular Programming: I learned to separate application responsibilities into modules such as `tickets.py`, `workflow.py`, `storage.py`, and `reports.py`. This makes code easier to understand, maintain, and test.

2\. Data Structures and Validation: I learned how to represent tickets using Python dictionaries, validate user input, generate unique ticket IDs, and normalize input consistently.

3\. Business Logic: I learned to implement priority calculation based on urgency and affected users, enforce valid ticket status transitions, assign responsibilities, and organize work queues by priority.

4\. File Handling and Persistence: I learned how to save and load ticket records using JSON, handle missing files, and preserve application data between sessions.

5\. Automated Testing: I learned to write unit and integration tests using Python's `unittest` framework, test edge cases, interpret test failures, and verify changes by running the complete test suite.
6\. Command-Line Interfaces: I learned how to connect separate modules through a menu-driven application, handle errors, and provide users with a consistent interface.
7\. Git and GitHub Collaboration: I learned about branches, commits, pull requests, issue tracking, code reviews, and safe integration of contributions from multiple developers.
Overall, CampusFlow strengthened my understanding of building, testing, documenting, and collaborating on a real-world Python project.
8\. Built-in python function: I learnt how to make use of the ".strip()" method.
